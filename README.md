## How I work

1. **Clarify the outcome** — identify the user journey, reliability needs,
   security constraints, and operating cost before selecting services.
2. **Build for repeatability** — use modular code, explicit configuration, and
   validation steps so environments can be reviewed and reproduced.
3. **Document the handoff** — explain deployment, monitoring, limitations, and
   sensible next improvements in plain language.
